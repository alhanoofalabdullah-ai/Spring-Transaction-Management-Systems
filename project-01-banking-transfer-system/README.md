# Banking Transfer System

Enterprise banking transaction system built using Spring Boot and Spring Transaction Management.

## Features

- Account management
- Money transfer
- Transaction handling
- Automatic rollback
- Data consistency
- REST API

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- Spring Transactions
- MySQL

## API Endpoints

### Transfer Money

POST /transfer

Example:

{
  "fromAccount": 1,
  "toAccount": 2,
  "amount": 500
}
