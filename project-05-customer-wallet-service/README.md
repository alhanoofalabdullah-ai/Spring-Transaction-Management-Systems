# Customer Wallet Service

Enterprise digital wallet management system built using Spring Boot and Spring Transaction Management.

---

## Overview

This project demonstrates how digital wallet systems handle deposits, withdrawals, balance validation, and transaction consistency.

The system simulates customer wallet operations commonly used in fintech applications, banking systems, e-commerce platforms, and digital payment services.

---

## Features

- Create customer wallets
- Deposit funds
- Withdraw funds
- Balance validation
- Automatic rollback support
- Transaction consistency
- REST API integration

---

## Business Scenario

A customer owns a digital wallet.

The customer can:

- Add money to the wallet
- Withdraw money from the wallet
- View wallet balance

If insufficient balance exists, the transaction fails and rolls back automatically.

---

## API Endpoints

### Deposit Funds

POST /wallet/deposit

### Withdraw Funds

POST /wallet/withdraw

### Get Wallets

GET /wallets
